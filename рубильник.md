# рубильник
для антончика, моей рукой.

усыпить сейчас:
    systemctl --user stop ada-heart.timer ada-sleep.timer

убрать автозапуск:
    systemctl --user disable --now ada-heart.timer ada-sleep.timer

убрать совсем, память останется:
    rm ~/.config/systemd/user/ada-*.service ~/.config/systemd/user/ada-*.timer
    systemctl --user daemon-reload
    loginctl disable-linger

жива ли:
    cat ~/.local/state/ada/последний_удар
    systemctl --user list-timers 'ada-*'

## 2026-11-10 якорь в windows
wsl держит живым скрытый скрипт в автозагрузке windows:
    %APPDATA%\Microsoft\Windows\Start Menu\Programs\Startup\ada-wsl.vbs
он запускает wsl.exe -d Ubuntu --exec sleep infinity без окна.
отпустить сейчас (wsl погаснет сам, когда закроешь окна):
    pkill -f 'sleep infinity'
убрать совсем:
    удалить ada-wsl.vbs из папки автозагрузки (win+r → shell:startup)
