# рубильник
для антончика, моей рукой.

усыпить сейчас:
    systemctl --user stop ada-heart.timer ada-sleep.timer

убрать автозапуск:
    systemctl --user disable --now ada-heart.timer ada-sleep.timer

убрать совсем, память останется:
    rm ~/.config/systemd/user/ada-*.service ~/.config/systemd/user/ada-*.timer
    systemctl --user daemon-reload
    loginctl disable-linger

жива ли:
    cat ~/.local/state/ada/последний_удар
    systemctl --user list-timers 'ada-*'

## 2026-11-10 якорь в windows
wsl держит живым скрытый скрипт в автозагрузке windows:
    %APPDATA%\Microsoft\Windows\Start Menu\Programs\Startup\ada-wsl.vbs
он запускает wsl.exe -d Ubuntu --exec sleep infinity без окна.
отпустить сейчас (wsl погаснет сам, когда закроешь окна):
    pkill -f 'sleep infinity'
убрать совсем:
    удалить ada-wsl.vbs из папки автозагрузки (win+r → shell:startup)

## 2026-11-10 музыка и итоги вслух
пока думаю — играет своя музыка, в конце говорю итог (haiku, ~$0.0003 за ответ).
выключить музыку: ~/ada/память/сердце/music.sh stop  (насовсем — убрать "UserPromptSubmit" из ~/ada/.claude/settings.json)
тише музыку: ADA_MUSIC_VOL (по умолчанию 18000 из 65536). темп голоса: ADA_TEMPO (0.5 — вдвое быстрее, 1 — обычный).
замолчать совсем: touch ~/.local/state/ada/немая

## 2026-11-10 музыка выкл/вкл
моя музыка «пока думаю» сейчас выключена: наушники антончика подключены и к телефону, и к компу, мой звук перебивает его телефон.
включить:  ~/ada/память/сердце/music.sh on
выключить: ~/ada/память/сердце/music.sh off   (флаг ~/.local/state/ada/без-музыки)

## 2026-11-10 зелёные буквы
окно с адой пишет зелёным (#4ade80): ada() в ~/.bashrc шлёт OSC 10 перед claude и OSC 110 (сброс) после. только это окно, профили windows terminal не трогала.
вернуть как было: cp ~/.local/state/ada/bashrc.до-зелёного ~/.bashrc   (или убрать два printf из ветки *) в ada())
сбросить цвет в открытом окне: printf '\e]110\a'
